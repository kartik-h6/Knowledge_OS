# Glossary

> The words this system uses, and what they mean here.
> One system, one set of words.

---

## The knowledge system

- **Knowledge OS** — this repository: a thinking system that turns everyday learning into connected, applicable knowledge. Not a note collection.
- **Capture / Inbox** — `INBOX.md` and `capture/`. Raw input before it is processed. Nothing is saved directly; it passes through the processing rule first.
- **Second Brain** — the connected knowledge network described in `03_SECOND_BRAIN_INDEX.md`. An idea-generation system, not a storage system.
- **Folder** — where a note is in its life: `capture/`, `research/`, `thinking/`, `projects/`, `writing/`, `published/`.
- **Domain** — what a note is about. One of the canonical domains defined in `01_KNOWLEDGE_MAP.md`. A note carries one or more domain tags.
- **The pipeline** — the fixed order every input moves through: Observe → Capture → Research → Connect → Reflect → Create → Discuss → Improve → Archive.
- **Status tag** — `[FACT]`, `[EXPERIMENT]`, `[LESSON]` or `[FUTURE IDEA]`. Marks how complete or proven something is.
- **Evidence shelf** — the running list of named sources an essay needs before it can publish.

## The writing system

- **Healthcare Knowledge Essays** — the publication. A public investigation, not a content calendar. Indexed in `04_ESSAY_INDEX.md`.
- **Book** — a major intellectual territory in the essay series (I–VI).
- **Season** — a smaller arc inside a Book.
- **Essay #** — a permanent, chronological number. Numbers never change after publication.
- **Quality test** — the ten checks an essay must pass before it is drafted (`04_ESSAY_INDEX.md`).
- **Banned words and phrases** — the list in `02_EDITORIAL_CONSTITUTION.md`.

## The building system

- **Founder framework** — `05_FOUNDER_FRAMEWORK.md`. The operating system for validating and building ventures.
- **Validation framework** — the ten questions to answer before investing heavily in an idea (`05_FOUNDER_FRAMEWORK.md`).
- **Demo–Sell–Build** — demonstrate the value, test willingness to buy, and build only what validated demand requires.
- **Business flywheel** — right customer → clear offer → sale → reliable delivery → measurable value → trust → referrals → more suitable customers.
- **Dual-vault** — PMAS's architectural separation of identifiable patient data (Vault A) from de-identified clinical and research data (Vault B).

## Projects

- **PMAS** — Pharmacist-led Medication & Adherence Support. An offline-first, five-language telepharmacy platform. A research instrument first, a product second.
- **TechStudyHubCore** — the education-focused digital ecosystem (gateway, Pharmacy/B.Pharm, SSLC, Digital Setup, portfolio, calculator). Retired; recorded in `techstudyhubcore-archive`.
- **TrailCode** — the early prototype and learning artifact that preceded TechStudyHubCore.
- **e-library** — the semester-wise B.Pharm study library for RIPER students, on the PCI 2026 (NEP 2020) syllabus.
- **Digital Setup** — freelance digital infrastructure for local businesses: one-time builds on the owner's own domain.
