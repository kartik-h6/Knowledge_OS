# Claude Code installation

Copy `.claude/skills/` into either:
- the project root as `.claude/skills/`, or
- your user-level `~/.claude/skills/` directory.

Invoke skills using their folder names, e.g. `/linkedin-post`.

These skills are intentionally self-contained and repeat the critical editorial rules so they work without a separate memory system. Keep `../reference/EDITORIAL_CONSTITUTION.md` as the canonical full reference.
